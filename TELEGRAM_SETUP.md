# PRIME v1 — Telegram Mini App launch

## What this version does

- One persistent PRIME account per Telegram user.
- Secure server-side validation of `Telegram.WebApp.initData`.
- PostgreSQL profiles, PRIME Score, ELO and histories.
- Global leaderboard.
- Per-user music upload, playback and deletion.
- Gemini AI advice and face analysis through the backend only.
- Existing PRIME UI is preserved.

Telegram recommends validating `initData` on the backend before trusting user data.

## 1. Deploy PRIME

The repository includes `render.yaml` for a Render deployment with:

- a Docker web service;
- managed PostgreSQL;
- a persistent disk for `/app/media` so uploaded music survives restarts/deploys.

Because persistent disks are not available on Render Free web services, the first real version uses a paid web service/disk.

After deployment, copy the HTTPS service URL, for example:

`https://prime-mini-app.onrender.com`

Check:

`https://prime-mini-app.onrender.com/health`

It must return JSON containing `status: ok`.

## 2. Configure secrets in Render

Set these environment variables in the web service:

- `GEMINI_API_KEY` — your Gemini key.
- `TELEGRAM_BOT_TOKEN` — the token from @BotFather.

`PRIME_JWT_SECRET` is generated by the Render Blueprint.

Never commit these values to Git.

## 3. Configure the Telegram Mini App

In Telegram, open @BotFather and configure the bot's Main Mini App / Mini App URL to the HTTPS Render URL.

Telegram will load `telegram-web-app.js`, and PRIME automatically sends the signed `initData` to `/api/auth/telegram`.

The backend validates the Telegram signature with the bot token, creates the user's account on first launch, and returns a PRIME JWT.

## 4. First launch test

Open the Mini App from Telegram and verify:

1. A profile is created automatically.
2. Photo analysis saves a history entry.
3. ELO match changes the rating and saves history.
4. Leaderboard shows the account.
5. Uploaded music appears only in that user's library.
6. Music can be played and deleted.
7. AI advice works when `GEMINI_API_KEY` is configured.

No API key or bot token belongs in the repository.
